# QuickNote v0.1 第一版 MVP

2026-10-22 的交付范围是可本地安装、可日常使用的 Windows 文字便签应用。按维护者本次要求，签名申请和人工发布审核不阻塞实现与未签名安装包交付。公开签名发行的验证记录仍在 Issue #22 单独维护，尚未执行的项目不会记为通过。

## 使用

支持 Windows 11 25H2 或更新版本的 x64 系统。运行 `QuickNote-0.1.0-x64.msi` 安装到当前用户；也可以解压便携包并运行 `QuickNote.exe`。本次产物未签名，Windows 可能显示未知发布者提示。

- 按 `Ctrl+Alt+Q` 快速继续当前便签，正文自动保存。`Esc` 或点击其他应用收起快速记录。
- 主页 `Ctrl+N` 新建，`Ctrl+F` 聚焦搜索。空白草稿不会生成便签；第一行非空文字就是标题。
- 关闭主页会留在托盘；右击托盘可以快速记录、打开主页或退出。只有明确退出才结束后台进程。
- 活跃便签可以归档；归档便签可取消归档或经确认移到回收站；回收站可恢复到归档或永久清除，保留期为 30 天。
- 主页可预览轻量 Markdown，搜索活跃及归档的完整正文。外部链接需要明确点击。
- 截止时间和提醒使用本地时间 `YYYY-MM-DD HH:MM` 输入。未来截止时间会在提醒为空时默认安排同刻提醒；二者可以独立清除。
- 设置中可调整快捷键、登录启动、稍后提醒时长、导出 JSON/Markdown、立即备份并查看许可证。
- 导出使用系统保存对话框选择位置，已有文件会要求确认。导出的明文副本不会随应用内的永久清除自动删除。

## 数据与恢复

数据存放在 `%LOCALAPPDATA%\QuickNote`，与程序目录分开；卸载默认保留数据。每个自然日首次成功写入后备份一致数据库快照；保留最近 7 个每日快照和最近 4 周快照，最长 30 天。备份失败不阻止正文保存，设置中会显示错误并允许重试，后台一小时后或下次启动重试。

异常退出或七天未检查时执行数据库健康检查。检测到损坏后保留原始数据库、WAL/SHM，并显示恢复界面；可以选择有效备份、打开数据目录或明确确认新建空库。未作选择便退出时，下次启动仍停留在恢复流程。恢复成功后也保留故障副本供用户检查。

永久清除会清理正文、提醒载荷及动作收据，移除可能包含旧正文的自动备份，再创建干净快照。系统通知取消会同时移除已投递历史；暂未完成的平台取消仅保留不含正文的操作标识。备份历史无法删除时不会宣告永久清除成功，自动清理失败会保留便签并显示维护警告，仍可打开其余健康便签。用户自行导出的文件和故障隔离副本由用户管理。

JSON 导出包含应用版本，领域时间统一为 ISO 8601 UTC；Markdown front matter 保留独立提醒时间，文件名使用安全标题和便签短标识。此版本不提供 JSON 导入。

## 构建与验证

```powershell
# 验证领域合同、故障恢复与共享 UI 键盘旅程。
cargo fmt --all --check
cargo clippy --locked --workspace --all-targets -- -D warnings
cargo test --locked --workspace

# 构建未签名 Release、检查运行时和安装器，并生成 MSI、便携 ZIP、SHA-256 清单。
.\scripts\New-QuickNoteMvp.ps1

# 在随机临时数据目录验收刚生成的程序，结束后恢复原有产品注册。
.\scripts\Test-QuickNoteMvp.ps1 `
  -ExecutablePath .\artifacts\mvp\QuickNote-0.1.0-x64\QuickNote.exe
```

构建产物默认位于 `artifacts\mvp`。脚本读取 Cargo 的真实构建目录，支持本机重定向到 D 盘；不需要签名证书，也不要求等待外部审核。

2026-10-22 已通过 49 项默认自动测试、独立规模搜索和真实 Windows 通知验收、7 项真实界面旅程、Clippy 与 Release 构建。冷启动 P95 为 276 ms，快捷键热唤起 P95 为 62 ms。交付包、测试证据与复现方式汇总于 [PR #37](https://github.com/eelevenn/quicknote/pull/37) 及其中的最终复核记录。

当前 MVP 不包括语音、同步、账户、JSON 导入或自动更新。完整 Narrator、真实睡眠、Explorer 重启和干净系统升级故障矩阵仍需对应环境实测，不能由单元测试替代。
