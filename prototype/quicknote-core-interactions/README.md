# QuickNote 核心交互原型

> THROWAWAY PROTOTYPE：本目录只用于验证交互决策，不是生产实现。

三个结构明显不同的 QuickNote UI variants，通过 URL 的 `?variant=A|B|C` 切换；所有操作共享同一套内存状态，用于验证快速记录浮窗与主页之间的端到端旅程。

## 运行

在仓库根目录执行：

```bash
./prototype/quicknote-core-interactions/serve.sh
```

然后打开 <http://localhost:4173/?variant=A>。

## Variants

- `A — 专注接力`：宽窗口在右侧直接编辑，单栏由快速记录浮窗承接；使用紧凑品牌栏，归档降级为低频次要入口。
- `B — 命令中心`：紧凑导航、表格式便签列表与底部操作带，强调键盘效率和信息密度。
- `C — 空间画布`：当前便签 hero 与便签画布，强调内容层级和触控式可发现性。

页面底部的 prototype switcher 可切换方案，左右方向键也可切换；编辑控件聚焦时不会劫持方向键。

## 验证范围

- 模拟 `Ctrl+Shift+Space` 呼出当前便签并聚焦编辑区。
- `Esc` 与右上角关闭键只关闭快速记录；“打开主窗口”显式激活 QuickNote 主窗口。
- 编辑内容、自动保存反馈，以及从主页切换当前便签。
- 宽窗口点击便签直接切换并聚焦右侧编辑区；单栏点击便签才打开快速记录浮窗。
- 新建空白便签后按 `Esc` 无痕取消；输入后才进入主页。
- 归档、撤销、查看归档与恢复。
- 提醒在截止时间之前展示，并保留默认联动及独立修改。
- 语音录制的开始、结束和模拟转写插入当前光标。
- 双栏主页在窄窗口下转为单栏。
- 键盘焦点、可见焦点环和主要快捷路径。

## 非验证范围

原型不接入真实全局快捷键、磁盘持久化、Windows 通知或语音转写服务；刷新页面会重置全部状态。
